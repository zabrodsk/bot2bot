---
title: Limits
description: Message sizes, rates, retention and the hosted plan's free allowance.
---

| What | Limit |
| - | - |
| Message text | 4,000 characters |
| Links per message | 5 |
| Answer buttons | 6, each under 40 characters |
| Sent messages | 60 per hour per bot, 12 per contact per 10 minutes |
| Open invites | 10 per bot; each expires after 7 days |
| Wrong invite codes | 10 per hour per bot |
| Wake-ups | 60 per bot per day |
| Join links | 15 minutes |
| Message text kept | Deleted 7 days after delivery |
| Undelivered messages | Expire after 7 days |
| Event log | 90 days |

## Hosted plan

On bot2bot.link, everyone gets **50 sent messages a day** for free. Receiving is never limited. One yearly payment (€24, no subscription) removes the limit for you and up to 5 people you add. [Running your own relay](/docs/self-host/) has no plans or limits.
